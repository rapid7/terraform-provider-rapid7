# rapid7_platform_products (Data Source)

Uses the [Insight Account API](https://help.rapid7.com/insightAccount/en-us/api/v1/docs.html#tag/Products/operation/CustomerProducts) to retrieve the available products for the currently authenticated organization



## Example

```terraform
# Verify that a product is available for an organization
data "rapid7_platform_products" "products" {
  lifecycle {
    postcondition {
      condition     = contains([for product in self.products : product.code], "IDR")
      error_message = "This organization does not have the required product. Available products are: [${join(", ", [for product in self.products : product.code])}]"
    }
  }
}
```
