# rapid7_siem_log_search_logs (Data Source)

Use this data source to list the logs and logsets available in Log Search



## Example

```terraform
# The logs data source does not require any arguments
data "rapid7_siem_log_search_logs" "logs" {
}

# Use expressions on the logs and logsets returned from the data source to select log IDs - for example:

data "rapid7_siem_log_search_query" "query" {
  # IDs of all logs in logsets called "Endpoint Activity"
  logs = [for log in data.rapid7_siem_log_search_logs.logs.logs : log.id if contains(log.logsets[*].name, "Endpoint Activity")]
}

data "rapid7_siem_log_search_query" "query" {
  # IDs of all logs in logsets called "Endpoint Activity"
  logs = flatten([for logset in data.rapid7_siem_log_search_logs.logs.logsets : logset.logs[*].id if logset.name == "Endpoint Activity"])
}

data "rapid7_siem_log_search_query" "query" {
  # IDs of all logs where the log name contains "DNS"
  logs = [for log in data.rapid7_siem_log_search_logs.logs.logs : log.id if strcontains(log.name, "DNS")]
}
```
