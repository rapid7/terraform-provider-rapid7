# Changelog

## 1.1.0 (2026-09-16)

### New Data Sources

* `rapid7_platform_managed_organizations`: Data source to list organizations that are managed tenants of a multi-tenant environment
* `rapid7_platform_products`: Data source to list the available products for the currently authenticated organization

### New Actions

* `rapid7_siem_detection_rule_override_remove`: Action to remove any override that may be applied to a detection rule

## 1.0.1 (2026-07-28)

### New Data Sources

* `rapid7_siem_log_search_logs`: Data source to list the logs and logsets available in Log Search
